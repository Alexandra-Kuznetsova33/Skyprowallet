# SkyProWallet — приложение для учёта личных расходов

Учебный проект, разработанный в рамках курса SkyPro.  
Позволяет добавлять, просматривать и анализировать расходы с удобной визуализацией.

## 🔧 Функциональность

- **Регистрация и авторизация** с кастомной валидацией полей (красная обводка, сообщение об ошибке).
- **Главная страница «Мои расходы»**:
  - Форма добавления нового расхода с выбором категории (иконки SVG) и валидацией (лейблы с красной звёздочкой при ошибке).
  - Таблица всех расходов с возможностью удаления (иконка корзины, меняющая цвет при наведении).
  - Кастомный скроллбар в таблице.
- **Страница «Анализ расходов»**:
  - Выбор периода через встроенный календарь (скроллируемый, без стрелок, 7-колоночная сетка).
  - Столбчатая диаграмма расходов по категориям за выбранный период.
  - Фильтр по категории.
- **Адаптивная вёрстка** с использованием `styled-components`, Flex и Grid.
- **Клиентская маршрутизация** через React Router v6.
- **Сохранение данных в localStorage** (пользователи, расходы).
- Защищённые маршруты (ProtectedRoute).

## 🛠 Технологии

- React 18
- React Router v6
- Styled-components
- Vite (сборка)
- CSS Grid / Flexbox
- LocalStorage
- UUID (crypto.randomUUID)

## 🚀 Запуск проекта

1. Убедитесь, что у вас установлены Node.js (рекомендуется v16+) и npm.
2. Клонируйте репозиторий:
     git clone https://github.com/Alexandra-Kuznetsova33/Skyprowallet.git
3. Перейдите в папку проекта:
    cd Skyprowallet

4. Установите зависимости:
    npm install
    
5. Запустите сервер разработки:
    npm run dev
    
6. Приложение откроется по адресу http://localhost:3000.

##🧪 Сборка для production
    npm run build
    Готовые файлы появятся в папке dist.

##📌 Примечания
- Все данные (пользователи, расходы) хранятся локально в localStorage браузера, поэтому при очистке хранилища они удалятся.
- Валидация даты ограничена 2020 годом (минимально допустимый год).
- В поле «Сумма» разрешён ввод только цифр и точки.
- Проект создан с использованием styled-components, без внешних CSS-файлов компонентов (только глобальные переменные в App.css).
